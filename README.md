# Walker & West Events

Marketing site for Walker & West Events, a Kelowna event planning and venue/catering consulting business.

## Pages

| Route         | Page       |
| ------------- | ---------- |
| `/`           | Home       |
| `/about`      | About      |
| `/events`     | Events (corporate, non-profit, social) |
| `/consulting` | Consulting (venue, catering) |
| `/contact`    | Contact    |

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS v4.
